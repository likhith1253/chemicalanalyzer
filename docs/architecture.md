# System Architecture

ChemViz is built using a modern, decoupled full-stack architecture. By separating the frontend presentation layer from the backend processing and data storage layers, the application achieves high scalability, security, and maintainability.



## 1. The Frontend (React 18 + Vite)
The user interface is a Single Page Application (SPA) built with React.
- **Responsibility**: Rendering UI components, managing client-side state, capturing user input, and visualizing data via Chart.js.
- **Routing**: Client-side routing is handled by React Router v6, ensuring snappy page transitions without full browser reloads.
- **Communication**: It communicates asynchronously with the backend API using Axios, handling authentication tokens and CORS negotiations seamlessly.
- **Deployment**: Hosted on **Vercel**, leveraging its global CDN for lightning-fast asset delivery.

## 2. The Backend (Django + DRF)
The core logic resides in a monolithic Django backend, serving requests via the Django REST Framework (DRF).
- **Responsibility**: Authenticating users, validating file uploads, orchestrating data processing, interacting with external AI APIs, and generating PDF documents.
- **Data Processing (Pandas)**: The heavy lifting of CSV parsing and statistical calculation is delegated to Pandas, ensuring high throughput and vectorized performance.
- **API Design**: Exposes standard RESTful endpoints (`/api/upload/`, `/api/datasets/`) consumed by the React frontend.
- **Deployment**: Hosted on **Render**, running behind a production Gunicorn WSGI server and WhiteNoise for static asset serving.

## 3. The Database (PostgreSQL)
A robust relational database ensures data integrity.
- **Responsibility**: Persisting user accounts, raw equipment records, and cached analysis results.
- **ORM Integration**: Interacts exclusively through Django's Object-Relational Mapper (ORM), protecting against SQL injection and simplifying schema migrations.
- **Deployment**: A managed PostgreSQL instance provided by Render.

## 4. The AI Intelligence Layer (Google Gemini)
To provide actionable value beyond simple statistics, the system integrates with Google's Generative AI.
- **Responsibility**: Analyzing statistical payloads generated by Pandas to produce natural-language maintenance recommendations.
- **Integration**: The backend communicates securely with the `gemini-2.0-flash-exp` (or fallback) models via the official Google Python SDK.
